# ImageGen (proxy) — расширение SillyTavern

Порт логики Tavo-плагина в SillyTavern (ST). Бот в ответе вставляет маркер
`[IMG]english|русская подпись|Имя,ссылка;Имя2,ссылка[/IMG]` → расширение ловит его,
дёргает твой прокси генерации и вставляет картинку прямо в сообщение.

Серверную часть (прокси linkapi/naistera) **не трогаем** — расширение ходит в тот же GET-эндпоинт.

## Что уже умеет (MVP 0.1.0)
- Авто-картинка по маркеру `[IMG]…[/IMG]` в ответе бота.
- Ручная команда `/imagegen <english prompt>`.
- Панель настроек: прокси, провайдер, модель, стиль, userId, DATA (зашифрованные ключи с сайта).
- Отчёт о последней ошибке (с серверным логом Vercel, если прокси его отдаёт) + «Скопировать».

## Чего пока НЕТ (следующие итерации)
- Редакторы одежды/фона/причёски/внешности, avoid, выбор персонажей.
- Промпт-райтер (думалка).
- Реролл-UI (в ST есть нативные *swipes* — можно использовать их).
- Мульти-реф лиц нескольких персонажей (в ST нативно слабо; либо ComfyUI-воркфлоу).

## Установка
**Вариант А (из папки):** скопируй эту папку `st-imagegen` в
`SillyTavern/public/scripts/extensions/third-party/st-imagegen/` → перезапусти ST → включи в «Extensions».

**Вариант Б (по git-URL):** если зальёшь папку в git-репозиторий, в ST:
Extensions → Install extension → вставь URL репозитория.

## Настройка (всё в панели ST)
Открой Extensions → «ImageGen (proxy)»:
1. **DATA** — зашифрованный блок ключей с сайта-конструктора (шаг «зашифровать ключи»). Скопируй и вставь. Без него генерация не пойдёт.
2. **Провайдер / модель / стиль / userId** — выбираешь тут же (модель — выпадашка под провайдера).
3. **Персонажи (рефы)** — «+ добавить персонажа»: имя + ссылка на фото (i.ibb.co/...). Модель в маркере пишет только **имена**, ссылки расширение подставит само.
4. baseUrl по умолчанию = linkapi-прокси, менять не нужно.

## Промпт для бота (обязательно!)
ST сам не знает про маркер — модель надо научить его выдавать. Вставь этот блок в **Author's Note**
(или в system prompt / карточку персонажа):

```
=== IMAGE GENERATION ===
Somewhere in the MIDDLE of your reply insert ONE image marker (never at the very start).
Format: [IMG]English scene description|Русская подпись|Name;Name2[/IMG]
- PART 1: one English sentence describing the scene, using ONLY character names.
- PART 2: the same sentence in Russian (shown as caption).
- PART 3: names of characters in the scene, separated by ; (just names — no links).
Exactly ONE marker per reply. Do not write URLs or HTML anywhere else.
```

Имена в PART 3 должны совпадать с именами в разделе «Персонажи (рефы)» панели — по ним подставятся фото.

## Спрятать сам маркер (если остаётся текстом)
Расширение пытается убрать `[IMG]…[/IMG]` из видимого текста. Если на твоей версии ST
текст-маркер всё же мелькает — добавь **Regex** (Extensions → Regex → +):
- Find: `\[IMG\][\s\S]*?\[\/IMG\]`
- Replace with: (пусто)
- Affects: **Display** (галочка), можно оставить AI Output выкл.

## Ограничения / проверить вживую
- API ST местами меняется между версиями — если что-то не цепляется, смотри консоль браузера
  (F12) на строки `[ImageGen] …`.
- `appendMediaToMessage` / `updateMessageBlock` — из `SillyTavern.getContext()`; если у тебя старая
  версия ST, часть может отсутствовать (обёрнуто в try/catch, но картинка тогда может не вставиться
  без перезагрузки чата).
- Раздача юзерам: в отличие от Tavo (.tpg), тут юзер ставит ST + это расширение. DATA можно
  запечь в поле настроек или (позже) генерировать готовый пакет расширения прямо с сайта.
