# ImageGen (proxy) — расширение SillyTavern

Картинки по ходу ролёвки через твой прокси-генерации (как Tavo-версия). Серверную часть не трогаем.

## Два режима (в панели расширения)

**Авто (по умолчанию, рекомендуется) — карточку/пресет НЕ трогаешь.**
Бот пишет обычный ответ → расширение вырезает служебные теги ([HUD]/[IM]/<think> и т.п.),
шлёт прозу в промпт-райтер → генерит картинку → вставляет её **инлайн в текст** (после первого абзаца).
Работает с любой карточкой, ничего в промт вставлять не надо.

**Маркер [IMG]** — для тех, кто хочет точный контроль: модель сама пишет
`[IMG]eng|rus|Name;Name2[/IMG]`, расширение заменяет его инлайн-картинкой.
(Для тяжёлых карточек со своей системой тегов маркер часто игнорится — тогда бери Авто.)

## Установка
Extensions → Install extension → вставь URL репозитория. Перезапусти/обнови страницу (F5).

## Настройка (всё в панели)
- **DATA** — зашифрованный блок ключей с сайта-конструктора (кнопка «📋 DATA» на шаге шифрования).
- **Режим** — Авто / Маркер. **Частота** (авто) — каждый ответ / каждый 2-3-й.
- **Провайдер / модель / стиль / userId** — как на сайте (провайдер = тот же, что при шифровании).
- **Персонажи (рефы)** — имя + ссылка на фото. Если имя встречается в ответе — подставится его фото.

## Команды
- `/imagegen <english prompt>` — картинка по промпту, отдельным сообщением (быстрый тест).
- `/imgnow` — сгенерить картинку по последнему ответу бота (инлайн), вручную.

## Отладка
Консоль браузера (F12): строки `[ImageGen] …`. Отчёт о последней ошибке — в панели, с серверным логом Vercel.

## Оговорки
- Промпт-райтеру нужен CORS на его прокси (vision-proxy-tavo). Если авто-режим ругается «промпт-райтер недоступен (CORS?)» — надо добавить CORS-заголовки в этот прокси.
- В кастомные карточки, чьё тело подменяет чужой регекс, инлайн-вставка может не лечь — тестируй на обычных ответах.
